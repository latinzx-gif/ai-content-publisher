4. ตั้ง Branch Manager

ขั้นตอนที่ลูกค้าทำเองหลัง handoff

  1. กำหนด role ให้พนักงาน Login HR/Admin → /admin/employees → ตั้ง role = branch_manager + กำหนดสาขา
  2. ผูก BM กับสาขา (1:1) ไป /admin/branches → สร้าง/แก้สาขา → เลือก Manager
  3. ทดสอบ flow BM login LINE → /admin/branch → อนุมัติคิว → ส่งต่อ HR
