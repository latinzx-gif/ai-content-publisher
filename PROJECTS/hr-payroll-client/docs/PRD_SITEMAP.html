1. Dashboard ภาพรวมระบบ System Dashboard

หน้าหลักของ Web Admin — แสดงภาพรวมสถานะขององค์กรแบบ Real-time

📊 แผงภาพรวม (Overview Cards)

แสดงตัวเลขสถานะแบบการ์ดสรุปทันทีเมื่อเข้า Dashboard

  • จำนวนพนักงานทั้งหมด / ประจำวันนี้
  • จำนวนเข้างาน เช็คอินแล้ว / ยังไม่เช็คอิน
  • จำนวนพนักงานลา / ขาด / มาสายวันนี้
  • จำนวนคำร้องรอดำเนินการ (ลา/เอกสาร/ร้องเรียน)
  • การแจ้งเตือนด่วน (ทดลองงานใกล้ครบ, วีซ่าใกล้หมด)

📈 กราฟและสถิติ

แสดงแนวโน้มข้อมูลในรูปแบบกราฟเพื่อให้ผู้บริหารเห็นภาพ

  • กราฟการเข้างานรายวัน / รายสัปดาห์ / รายเดือน
  • สัดส่วนประเภทการลา (ป่วย, ลากิจ, พักร้อน)
  • สถิติสาย-ขาด-ลา รายแผนก
  • อัตราการเข้างาน (Attendance Rate) %
🔵 P1 — Core

2. Dashboard ข้อมูลพนักงาน Employee Data Dashboard

ระบบจัดการข้อมูลบุคลากรแบบครบวงจร — ดู แก้ไข ติดตามสถานะพนักงาน

👥 รายชื่อพนักงาน

แสดงรายการพนักงานทั้งหมด ค้นหาและกรองได้

  • ตารางรายชื่อ แบบเรียงลำดับได้
  • ค้นหาตามชื่อ, แผนก, ตำแหน่ง, สถานะ
  • กรองตามสถานะ: ปฏิบัติงาน, ทดลองงาน, ลาออก
  • แสดงรูปโปรไฟล์พนักงาน

📋 ข้อมูลรายบุคคล (Profile)

หน้าข้อมูลพนักงานแบบละเอียด

  • ข้อมูลส่วนตัว: ชื่อ-นามสกุล, ที่อยู่, เบอร์โทร, อีเมล
  • ข้อมูลสัญญาจ้าง: ตำแหน่ง, แผนก, วันที่เริ่มงาน, วันที่สิ้นสุดสัญญา
  • ข้อมูลเงินเดือน: เงินเดือน, ค่าจ้างรายวัน, เลขที่บัญชี
  • สถานะวีซ่า / Work Permit (สำหรับแรงงานต่างด้าว)
  • สถานะทดลองงาน: วันที่เริ่มทดลอง, วันที่ครบกำหนด
  • ประวัติการลา + ยอดวันลาคงเหลือ
  • ประวัติการเช็คอิน-เช็คเอาท์

🔔 การแจ้งเตือนเกี่ยวกับพนักงาน

  • ระบบแจ้งเตือนพนักงานทดลองงานใกล้ครบกำหนด (Probat​ion)
  • ระบบแจ้งเตือนวีซ่า / Work Permit ใกล้หมดอายุ
  • ระบบแจ้งเตือนสัญญาจ้างใกล้สิ้นสุด
🔵 P1 — Core

3. ระบบเช็คอิน-เช็คเอาท์ Check-in / Check-out

พนักงานลงเวลาเข้างาน-เลิกงานผ่าน LINE OA พร้อมบันทึกตำแหน่งที่ตั้ง

📍 เช็คอินเข้างาน

  • กดปุ่มเช็คอินผ่าน LINE Rich Menu
  • ระบบบันทึกเวลาเข้างาน (Timestamp) + ตำแหน่ง Geo Location
  • แจ้งเตือนยืนยันการเช็คอินผ่าน LINE Flex Message
  • เช็คสาย: ถ้าเกินเวลาที่กำหนด แสดงข้อความแจ้งเตือนว่า "มาสาย"
  • รองรับการเช็คอินผ่าน QR Code (สแกนหน้างาน)

🚪 เช็คเอาท์เลิกงาน

  • กดปุ่มเช็คเอาท์เพื่อบันทึกเวลาเลิกงาน
  • สรุปชั่วโมงทำงานของวันนั้น (เช็คอิน → เช็คเอาท์)
  • แสดงเวลาทำงานสุทธิ (หักเวลาพัก)

📅 ประวัติการเข้าออก

  • พนักงานสามารถดูประวัติการเช็คอิน-เช็คเอาท์ของตัวเองได้
  • แสดงข้อมูลรายวัน: เวลาเข้า, เวลาออก, ชั่วโมง, สถานะ (ปกติ/สาย)
💬 LINE Integration
  • Rich Menu มีปุ่มเช็คอิน / เช็คเอาท์
  • Flex Message ยืนยันผลการเช็คอินพร้อมเวลาและตำแหน่ง
  • Push Notification แจ้งเตือนให้เช็คอินทุกเช้า (ถ้ายังไม่เช็คอิน)
  • ข้อความสรุปการเข้างานประจำวันส่งให้พนักงานทาง LINE
🔵 P1 — Core

4. ระบบลางาน Leave Management

พนักงานขอลางานผ่าน LINE OA — HR อนุมัติผ่าน Web Dashboard

✍️ การขอลางาน (LINE)

  • เลือกประเภทการลา: ลาป่วย, ลากิจ, ลาพักร้อน, ลาคลอด, ฯลฯ
  • ระบุวันที่เริ่มลา - สิ้นสุด (เลือกหลายวันได้)
  • ระบุเหตุผล / แนบไฟล์ใบรับรองแพทย์ (optional)
  • ระบบแสดงยอดวันลาคงเหลือให้พนักงานเห็นก่อนส่ง
  • ส่งคำขอผ่าน LINE -> ระบบส่งไปยัง HR เพื่ออนุมัติ

✅ การอนุมัติ (Web Admin)

  • HR ดูรายการคำขอลางานใน Dashboard
  • อนุมัติ / ไม่อนุมัติ พร้อมระบุเหตุผล
  • ระบบหักยอดวันลาอัตโนมัติเมื่ออนุมัติ
  • LINE ส่งผลการอนุมัติกลับไปหาพนักงาน

📋 การจัดการและรายงาน

  • ปฏิทินวันลาของพนักงานในองค์กร
  • รายงานสถิติการลา รายเดือน / รายปี
  • ยอดวันลาคงเหลือของพนักงานแต่ละคน
  • ประวัติการลาทั้งหมด

5. ระบบขอเอกสาร Document Request

พนักงานขอเอกสารทางราชการ/บริษัทผ่าน LINE — HR ดำเนินการออกเอกสาร

📄 ประเภทเอกสาร

  • หนังสือรับรองเงินเดือน / รายได้
  • หนังสือรับรองการทำงาน
  • สลิปเงินเดือนย้อนหลัง
  • ใบรับรองการผ่านทดลองงาน
  • เอกสารอื่น ๆ ที่กำหนดโดยบริษัท

📝 ขั้นตอนการขอ

  • เลือกประเภทเอกสารจากเมนูใน LINE
  • ระบบอาจถามข้อมูลเพิ่มเติม เช่น ใช้ยื่นธนาคารไหน
  • ส่งคำขอถึง HR
  • HR ดำเนินการออกเอกสารและแจ้งพนักงาน
  • พนักงานรับเอกสาร ( Download / รับที่ออฟฟิศ / ส่งEMS )
  • ติดตามสถานะคำขอได้ทาง LINE

6. ช่องทางการร้องเรียน Whistleblowing / Complaint Channel

ช่องทางแจ้งเรื่องร้องเรียนหรือแจ้งเบาะแสแบบไม่เปิดเผยตัวตน ผ่าน LINE

🛡️ การแจ้งเรื่องร้องเรียน

  • พนักงานเลือก "แจ้งเรื่องร้องเรียน" จากเมนู LINE
  • ตัวเลือก: แจ้งแบบระบุตัวตน หรือ ไม่ระบุตัวตน
  • เลือกหมวดหมู่: สภาพแวดล้อมในการทำงาน, การเลือกปฏิบัติ, คุกคาม, ทุจริต, อื่น ๆ
  • เลือกระดับความเร่งด่วน: ปกติ / ด่วน / ด่วนมาก
  • กรอกรายละเอียด / แนบไฟล์หรือรูปภาพ (ถ้ามี)
  • ส่งเรื่องเข้า Web Admin ให้ HR/ผู้บริหารจัดการ

🔐 การจัดการและการตอบกลับ

  • HR ดูรายการเรื่องร้องเรียนใน Web Dashboard
  • กำหนดสถานะ: รับเรื่อง / กำลังดำเนินการ / ดำเนินการเสร็จ
  • ตอบกลับพนักงาน (กรณีระบุตัวตน) ผ่าน LINE
  • บันทึกประวัติการดำเนินการทุกขั้นตอน
💬 LINE Integration
  • ใช้ LIFF (LINE Front-end Framework) สำหรับฟอร์มร้องเรียนแบบหลายขั้นตอน
  • ตัวเลือกระบุตัวตน / ไม่ระบุตัวตน (Anonymous)
  • ยืนยันการรับเรื่องผ่าน Flex Message
🔵 P1 — Core

7. ระบบแจ้งเตือนทดลองงานและวีซ่า Probation & Visa Alerts

ระบบติดตามและแจ้งเตือนอัตโนมัติเมื่อพนักงานใกล้ครบกำหนดทดลองงาน หรือวีซ่า/Work Permit ใกล้หมดอายุ

⏰ แจ้งเตือนทดลองงาน (Probation Alert)

  • ระบบนับถอยหลังวันที่ครบกำหนดทดลองงานของพนักงานแต่ละคน
  • แจ้งเตือน HR ก่อนครบกำหนด: 30 วัน, 14 วัน, 7 วัน, 1 วัน
  • แจ้งเตือนพนักงานผ่าน LINE เมื่อถึงวันครบกำหนด
  • HR สามารถบันทึกผลการประเมินทดลองงาน (ผ่าน/ไม่ผ่าน/ขยายเวลา)

🛂 แจ้งเตือนวีซ่า / Work Permit (Visa Alert)

  • ระบบบันทึกวันหมดอายุ Visa / Work Permit ของพนักงานต่างด้าว
  • แจ้งเตือน HR และพนักงานก่อนหมดอายุ: 60 วัน, 30 วัน, 14 วัน, 7 วัน, 1 วัน
  • แสดงรายชื่อพนักงานที่ Visa กำลังจะหมดอายุใน Dashboard
  • HR อัปเดตสถานะ Visa หลังจากต่ออายุแล้ว
  • แจ้งเตือนผ่าน LINE ทั้งถึง HR และพนักงาน
💬 LINE Integration
  • Push Notification ถึงพนักงานโดยตรงทาง LINE
  • Flex Message แสดงวันที่และรายละเอียดที่ชัดเจน
  • แจ้งเตือน HR ทาง LINE เช่นกัน (หรือ LINE Group)

📢 การสร้างประกาศ

  • รองรับ: ข้อความ, รูปภาพ, แนบไฟล์, ลิงก์
