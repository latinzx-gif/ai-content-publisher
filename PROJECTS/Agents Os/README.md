# Head Office Agent Studio

Native macOS desktop application scaffold for the PRD in `PRD_Head_Office_Agent_Studio.md`.

Current V1 scope implemented in this workspace:
- SwiftUI macOS app shell
- Sidebar navigation
- Project Dashboard
- Create Project form
- Local folder generator
- SwiftData persistence
- PRD Import screen
- Agent Library screen
- Skill Library screen
- Team Builder screen
- Runtime Manager screen
- Task Board screen
- Run Log screen
- Human Request Inbox
- Demo / Handoff Center
- Mock/manual task loop (no autonomous runtime integration yet)

Build:

```bash
cd "/Users/jakarinosk/Desktop/Agents Os"
swift build
```

Run:

```bash
cd "/Users/jakarinosk/Desktop/Agents Os"
swift run
```
