M5 — Task Board and Review Loop Hardening

เอกสาร Mockup การออกแบบนี้ใช้สำหรับขออนุมัติโครงสร้างหน้าตาและการไหลของระบบ (Visual Approval) ก่อนดำเนินการพัฒนาลงบน native macOS SwiftUI ในโครงการ Head Office Agent Studio สำหรับ Milestone 5

🟢 สิ่งที่คงไว้ (Keep) 🟡 สิ่งที่ปรับปรุง/เพิ่มใหม่ (Change) 🔴 จุดอ่อนเดิม/สิ่งที่เอาออก (Remove)

สิ่งที่คงไว้ (สิ่งที่คงอยู่จากเวอร์ชันเดิม)

  • Local-First Architecture: การทำงานแบบประมวลผลในเครื่องของผู้ใช้เป็นหลัก ปลอดภัยและรวดเร็ว
  • Manual/Mock Execution Only: ในเฟสนี้ยังคงใช้วิธีรันแบบ manual หรือจำลองจำกัดเพื่อความเสถียร
  • Create Task Form: ฟอร์มสำหรับการสร้าง task ใหม่ยังคงพร้อมใช้งานในระบบ
  • Human Request Inbox Gate: กล่องรับเรื่องความช่วยเหลือและการอนุมัติจากมนุษย์ (Human approval gate) ยังคงทำหน้าที่เป็นปราการหลักในการควบคุมคุณภาพการทำงานของเอเจนต์

2. Run Log Comparison

ปรับเปลี่ยนการแสดงผลล็อกการทำงาน (Run Log) จากข้อความ Plain text ดิบ ๆ ให้เป็นตารางข้อมูลที่มีโครงสร้างชัดเจนและคลิกเปิดดูผลลัพธ์ย่อยได้ง่าย

ผลลัพธ์ที่คาดหวังหลัง implement (Expected Outcomes)

  • ลดความสับสนบนกระดานบอร์ด: คอลัมน์ที่น้อยลงทำให้มองภาพรวมโปรเจกต์เสร็จสิ้นง่ายขึ้น และโฟกัสกับปัญหาที่กำลังเกิดขึ้นได้ทันที
  • ปรับปรุงความรวดเร็วในการ Debug: ตารางล็อกสเปคช่วยให้ทีมงานทราบว่ามี Artifact หรือคำร้องใดเกิด ณ เวลาไหน และลิงก์เปิดไฟล์ได้ในคลิกเดียว
  • ลดขั้นตอนการโต้ตอบกับเอเจนต์: ปุ่มตัดสินใจใน Inbox มีความเจาะจงต่อกระบวนการทำงาน ลดภาระความเหนื่อยล้าทางสมอง (Cognitive Load) ของมนุษย์ในการควบคุมทิศทาง
