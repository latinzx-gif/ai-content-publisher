M4 — Agent / Skill / Team Editing UX

Mockup นี้ใช้สำหรับดูทิศทางก่อนลงมือแก้ SwiftUI จริง โดยเป้าหมายคือทำให้ 3 หน้าหลักที่ยัง create-only ใช้งานซ้ำได้จริงขึ้นผ่าน edit sheets และ action buttons ต่อรายการ

เขียว = คงไว้ เหลือง = เพิ่ม/ปรับ แดง = จุดอ่อนปัจจุบัน

สิ่งที่คงไว้

  • โครงสร้างสองคอลัมน์: ฟอร์มซ้าย + รายการขวา
  • รูปแบบ Create form เดิม เพื่อไม่ทำให้ผู้ใช้เรียนรู้ใหม่ทั้งหน้า
  • Delete flow เดิมยังอยู่
  • แนวคิด local-first / manual-first ของ V1 เหมือนเดิม

ผลลัพธ์ที่คาดหวังหลัง implement

  • ผู้ใช้ไม่ต้องลบแล้วสร้าง Agent/Skill/Team ใหม่ทุกครั้งเมื่อข้อมูลเปลี่ยน
