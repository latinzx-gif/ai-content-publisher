# Head Office Application

The central operating system for Head Office content and agent orchestration.

## Primary Surfaces

- **Main Dashboard (PRD)**: `http://localhost:3001/`
- **Content OS Publisher**: `http://localhost:3001/publisher/`

```bash
cd head-office-app
npm run dev
```

Default Port: **3001**
