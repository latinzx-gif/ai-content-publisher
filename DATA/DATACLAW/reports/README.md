# README: Reports Data

## Purpose
This directory is the **output repository** for the DataClaw OS. It stores the final, polished, and sellable intelligence products that are delivered to customers.

While other directories manage raw facts and intermediate analysis, this folder contains the finished goods. Each item in this directory corresponds to a product listed in the `PRODUCT_CATALOG.md` and is the result of executing a `REPORT_PRODUCTION_PIPELINE`.
