# README: Insights Data

## Purpose
This directory stores "Insights," which are high-level conclusions synthesized by the `Analyst Agent`. An insight is distinct from a `Fact`. It is a logical assertion that connects multiple facts to reveal a pattern, trend, or "so what."

Insights are the core building blocks of our narrative intelligence products, such as `Insight Reports` and `Market Maps`. They represent the unique analytical value that DataClaw provides on top of the raw data we collect.
