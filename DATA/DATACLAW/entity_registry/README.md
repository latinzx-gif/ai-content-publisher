# README: Entity Registry

## Purpose
This directory acts as the central dictionary or glossary for the entire DataClaw OS. Its purpose is to store a unique, canonical record for every single named entity we track (e.g., a specific company, a person, an ingredient, a technology).

This process of entity resolution is critical for preventing data duplication and ambiguity. For example, it ensures that "Apple," the company, and "apple," the ingredient, are treated as two distinct entities. Every time a new entity is mentioned in another data asset, it must first be registered or linked here.
