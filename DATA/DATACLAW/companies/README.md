# README: Companies Data

## Purpose
This directory stores and manages all structured data related to individual companies. It serves as the foundational "who" layer of the DataClaw OS.

The data stored here is considered a **Fact-Based Asset**, meaning every entry must be verifiable and linked to a source. This asset is the primary source for building `Company Database` intelligence products and for enriching other data assets (e.g., linking a `Brand` to its parent `Company`).
