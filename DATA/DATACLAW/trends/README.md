# README: Trends Data

## Purpose
This directory stores and manages structured data on identified market trends. A "trend" is a pattern of change over time, synthesized by the `Analyst Agent` from a collection of discrete `facts` and `signals`.

This is a high-value analytical asset, not a raw data asset. It forms the core of `Trend Reports` and provides the forward-looking insights that differentiate DataClaw's intelligence products.
