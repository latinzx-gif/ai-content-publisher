### **2. Initial Setup Steps for You / ขั้นตอนการตั้งค่าเริ่มต้นสำหรับคุณ**

Before you can generate content, there are two important steps you need to complete on the **Settings** page:
*ก่อนที่คุณจะสามารถสร้างคอนเทนต์ได้ มีสองขั้นตอนสำคัญที่คุณต้องทำบนหน้า **Settings (การตั้งค่า)**:*

1.  **Create Your Brand Profile / สร้างโปรไฟล์แบรนด์ของคุณ:** Fill out the "Brand Profile" form with your company's details, target audience, and desired tone of voice. This is crucial for guiding the AI.
    *   *กรอกแบบฟอร์ม "Brand Profile" ด้วยรายละเอียดบริษัท กลุ่มเป้าหมาย และน้ำเสียงที่ต้องการ ซึ่งสำคัญมากในการแนะนำ AI.*
2.  **Enter Your API Keys / ป้อนรหัส API ของคุณ:** In the "Integrations" section, you will need to enter your API keys for OpenAI and Buffer. These are stored with strong encryption and are necessary for the application to function.
    *   *ในส่วน "Integrations" คุณจะต้องป้อนรหัส API สำหรับ OpenAI และ Buffer รหัสเหล่านี้จะถูกจัดเก็บด้วยการเข้ารหัสที่แข็งแกร่ง และจำเป็นสำหรับการทำงานของแอปพลิเคชัน.*

### **3. How to Use the Application / วิธีการใช้งานแอปพลิเคชัน**

1.  **Generate Content / สร้างคอนเทนต์:**
    -   Go to the "Generate" page. / *ไปที่หน้า "Generate".*
    -   Enter a simple topic (e.g., "the importance of cybersecurity for small businesses"). / *ป้อนหัวข้อง่ายๆ (เช่น "ความสำคัญของความปลอดภัยทางไซเบอร์สำหรับธุรกิจขนาดเล็ก").*
    -   Click "Generate". This uses "Quick Mode" and will automatically apply the best strategy based on your Brand Profile. / *คลิก "Generate" ระบบจะใช้ "Quick Mode" และจะปรับใช้กลยุทธ์ที่ดีที่สุดโดยอัตโนมัติตามโปรไฟล์แบรนด์ของคุณ.*
2.  **Approve Posts / อนุมัติโพสต์:**
    -   Navigate to the "Drafts" page to see the content the AI has created. / *ไปที่หน้า "Drafts" เพื่อดูคอนเทนต์ที่ AI สร้างขึ้น.*
    -   Review each post. If you like it, you are ready to publish. / *ตรวจสอบแต่ละโพสต์ หากคุณพอใจ ก็พร้อมที่จะเผยแพร่.*
    -   **(Current Limitation)** The "Approve" button in the UI is not yet active. For now, all drafts can be considered "approved for text". / *(ข้อจำกัดปัจจุบัน) ปุ่ม "อนุมัติ" ในหน้าจอใช้งานยังไม่ทำงาน ในตอนนี้ ถือว่าร่างคอนเทนต์ทั้งหมด "ได้รับการอนุมัติสำหรับข้อความ" แล้ว.*
3.  **Publish/Schedule / เผยแพร่/ตั้งเวลา:**
    -   From the Drafts page, click the "Publish" button on a post you like. / *จากหน้า Drafts คลิกปุ่ม "Publish" บนโพสต์ที่คุณต้องการ.*
    -   Select the social media channel you want to post to. / *เลือกช่องทางโซเชียลมีเดียที่คุณต้องการเผยแพร่.*
    -   Choose to either "Publish Now" or "Schedule for Later". / *เลือก "เผยแพร่ทันที" หรือ "ตั้งเวลาเผยแพร่ภายหลัง".*
