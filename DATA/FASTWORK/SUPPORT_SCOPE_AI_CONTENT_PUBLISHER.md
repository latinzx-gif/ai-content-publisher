# Support Scope: AI Content Publisher
## ขอบเขตการสนับสนุน: AI Content Publisher

### **Internal Notes / หมายเหตุภายใน:**
This document clearly defines the scope of support provided for a standard "AI Content Publisher" client delivery. It is intended to be shared with the client to manage expectations.

---

### **1. What Standard Support Covers / การสนับสนุนมาตรฐานครอบคลุมอะไรบ้าง**

Our standard support, included for 30 days post-delivery, covers issues related to the core functionality of the application.
*การสนับสนุนมาตรฐานของเรา ซึ่งรวมอยู่ในแพ็กเกจเป็นเวลา 30 วันหลังการส่งมอบ ครอบคลุมปัญหาที่เกี่ยวข้องกับการทำงานหลักของแอปพลิเคชัน ซึ่งรวมถึง:*

-   **Bug Fixes / การแก้ไขข้อผิดพลาด:** Any part of the documented functionality that is not working as described (e.g., you cannot save your Brand Profile, publishing to Buffer fails with an error).
    *   *ส่วนใดส่วนหนึ่งของการทำงานที่ระบุไว้ไม่ทำงานตามที่อธิบาย (เช่น ไม่สามารถบันทึกโปรไฟล์แบรนด์ได้, การเผยแพร่ไปยัง Buffer ล้มเหลว).*
-   **Deployment Issues / ปัญหาการติดตั้ง:** The application is inaccessible due to a deployment or platform error on Vercel.
    *   *แอปพลิเคชันไม่สามารถเข้าถึงได้เนื่องจากปัญหาการติดตั้งหรือแพลตฟอร์มบน Vercel.*
-   **Security Concerns / ข้อกังวลด้านความปลอดภัย:** Any suspected security vulnerabilities.
    *   *ข้อสงสัยใดๆ เกี่ยวกับช่องโหว่ด้านความปลอดภัย.*

**Response Time Expectation / ระยะเวลาการตอบกลับ:**
-   **For Critical Issues (e.g., app down):** 4-hour response time during standard business hours (9am-6pm, GMT+7).
    *   *สำหรับปัญหาระดับวิกฤต (เช่น แอปไม่ทำงาน): ตอบกลับภายใน 4 ชั่วโมง ในช่วงเวลาทำการมาตรฐาน (9:00-18:00 น. ตามเวลา GMT+7).*
-   **For Non-Critical Bugs:** 24-hour response time.
    *   *สำหรับข้อผิดพลาดที่ไม่วิกฤต: ตอบกลับภายใน 24 ชั่วโมง.*

---

### **2. What Standard Support Does NOT Cover / การสนับสนุนมาตรฐานไม่ครอบคลุมอะไรบ้าง**

The following are considered outside the scope of standard, included support:
*ต่อไปนี้ถือว่าอยู่นอกขอบเขตของการสนับสนุนมาตรฐานที่รวมอยู่ในแพ็กเกจ:*

-   **Third-Party API Issues / ปัญหา API บุคคลที่สาม:** We are not responsible for outages or changes in the OpenAI or Buffer APIs. If OpenAI is down, content generation will not work.
    *   *เราไม่รับผิดชอบต่อการหยุดชะงักหรือการเปลี่ยนแปลงของ OpenAI หรือ Buffer API หาก OpenAI ไม่ทำงาน การสร้างคอนเทนต์จะไม่สามารถทำได้.*
-   **AI Content Quality / คุณภาพคอนเทนต์ AI:** We are responsible for the prompt *generation system*, but not for the quality of any specific AI output. We do not offer support to "make a post sound better." This is handled by refining the Brand Profile or through a paid strategy retainer.
    *   *เราเป็นผู้รับผิดชอบ "ระบบสร้าง Prompt" แต่ไม่ใช่คุณภาพของคอนเทนต์ AI ที่ผลิตออกมา เราไม่ให้การสนับสนุนในการ "ทำให้โพสต์ดูดีขึ้น" ซึ่งต้องจัดการผ่านการปรับปรุง Brand Profile หรือบริการที่ปรึกษากลยุทธ์แบบมีค่าใช้จ่าย.*
-   **New Features / ฟีเจอร์ใหม่:** Requests for new functionality (e.g., "Can you add a LinkedIn integration?") are not support tickets. They are considered paid change requests.
    *   *คำขอฟังก์ชันการทำงานใหม่ (เช่น "เพิ่มการเชื่อมต่อ LinkedIn ได้หรือไม่?") ไม่ใช่ตั๋วสนับสนุน แต่ถือเป็นการร้องขอการเปลี่ยนแปลงโดยมีค่าใช้จ่าย.*
-   **Client-Side Issues / ปัญหาฝั่งลูกค้า:** Problems with the client's own computer, network, browser, or third-party accounts.
    *   *ปัญหาที่เกิดจากคอมพิวเตอร์ เครือข่าย บราวเซอร์ หรือบัญชีบุคคลที่สามของลูกค้าเอง.*

### **4. Paid Change Requests / คำขอเปลี่ยนแปลงโดยมีค่าใช้จ่าย**

Any work requested that falls outside the scope of bug fixes is considered a paid Change Request.
*งานใดๆ ที่ร้องขอซึ่งอยู่นอกขอบเขตของการแก้ไขข้อผิดพลาด จะถือว่าเป็นคำขอเปลี่ยนแปลงโดยมีค่าใช้จ่าย.*

-   **Process / กระบวนการ:**
    1.  Client submits a request via email. / *ลูกค้าส่งคำขอทางอีเมล.*
    2.  We will provide a formal scope of work (SOW) and a price quote. / *เราจะจัดทำขอบเขตงาน (SOW) และใบเสนอราคาอย่างเป็นทางการ.*
    3.  Work begins upon client approval of the SOW. / *งานจะเริ่มต้นเมื่อลูกค้าอนุมัติ SOW.*
-   **Examples / ตัวอย่าง:** Adding a new publishing platform, building a custom visual template, creating a new analytics report.
    *   *การเพิ่มแพลตฟอร์มเผยแพร่ใหม่, การสร้างเทมเพลตภาพลักษณ์ที่กำหนดเอง, การสร้างรายงานการวิเคราะห์ใหม่.*
