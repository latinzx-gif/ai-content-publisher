# README: Performance

## Purpose
This directory stores the calculated performance metrics and reports for the entire investment portfolio, as well as for individual strategies.

The data here is **derived** from the raw data in the `/trade_logs` directory. This is the "results" layer, where we transform the log of actions into actionable insights about what is working, what is not, and where the portfolio stands. It is the primary input for the `WEEKLY_REVIEW` and `MONTHLY_REVIEW`.
