# README: Trade Logs

## Purpose
This directory serves as the **immutable, append-only ledger** of every single trade or investment action taken by the INVESTMENT OS. It is the absolute source of truth for all positions and performance calculations.

The integrity of this log is paramount. Data in this directory should never be modified after it is written. Corrections should be made by appending a new, counteracting entry. This ensures a complete and auditable history of every action ever taken.
