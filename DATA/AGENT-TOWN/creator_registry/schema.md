# Schema: Creator Registry

## Purpose
To define the mandatory data structure for a single creator record. This schema ensures that all creator information is consistent, up-to-date, and sufficient for managing payouts and performance.

---

### Required Fields

| Field Name | Data Type | Description | Example |
|---|---|---|---|
| `creator_id` | String | A unique, machine-readable identifier for the creator. | `creator_jane_doe` |
| `creator_name`| String | The public-facing name or alias of the creator. | `Jane Doe` |
| `email` | String | The creator's private contact email for payouts and communication. | `jane.doe@example.com` |
| `status` | String | The current status of the creator. Must be one of: `Pending-Review`, `Active`, `Suspended`, `Retired`. | `Active` |
| `join_date` | Date | The date the creator was approved and became `Active`. | `2026-07-15` |
| `payout_info`| String | A reference ID for the creator's payment account (e.g., Stripe Connect Account ID). | `acct_1J2a3b4c...` |
| `total_downloads` | Integer | A calculated field showing the total number of downloads across all of the creator's packs. | `1520` |
| `total_revenue_usd`| Float | A calculated field showing the total revenue generated by the creator's packs. | `4500.50` |

---

### Scoring & Performance

-   **No Confidence Score:** Creator records are first-party data, not derived from external sources, so a confidence score is not applicable.
-   **Performance Tier:** A creator's performance can be tiered based on their metrics. This can be used for incentive programs.
    -   **Tier 1 (New):** < 100 downloads.
    -   **Tier 2 (Established):** 100 - 1,000 downloads.
    -   **Tier 3 (Top Creator):** > 1,000 downloads and > $1,000 total revenue.
