# SKILL: PRODUCT PLAN HTML

## GOAL
Turn plan into pretty HTML. For human look.

## INPUTS
- Task Gate (e.g. `graphify-out/gates/TASK-002_GATE.md`).
- `PROJECT_STATE.md` (Timeline).

## STEPS
1. Read markdown plan.
2. Build HTML structure. Use clean CSS.
3. Add status badges (READY, BLOCKED).
4. List Allowed and Forbidden files.
5. Save as `.html` for browser.

## OUTPUT
- Path to HTML file.
- Summary of plan status.

## STOP CONDITIONS
- Do not edit source code.
- Only create documentation artifact.
