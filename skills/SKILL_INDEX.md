# CODEX SKILL INDEX

This directory contains specialized skills for Codex implementation. Use these skills to maintain high engineering standards and project context.

## SKILL LIST

1. **[Bug Fixer](./bug-fixer.md)**: Find and fix bugs without breaking dependencies.
2. **[Code Reviewer](./code-reviewer.md)**: Audit code quality and check against `AGENTS.md` rules.
3. **[Refactor Simplifier](./refactor-simplifier.md)**: Clean up duplicate logic and remove mess.
4. **[Product Plan HTML](./product-plan-html.md)**: Visualize implementation gates for human review.
5. **[Database Insight Readonly](./database-insight-readonly.md)**: Map schema relationships and check data integrity.
6. **[Release Audit](./release-audit.md)**: Final verification before client handoff.

## RULES
- Read the skill file fully before starting the task.
- Use `PROJECT_STATE.md` (root) and `graphify-out/GRAPH_REPORT.md` (local) for context.
- Always check `git status` first.
- If task requires implementation -> Use the **Implementation Gate** workflow.
