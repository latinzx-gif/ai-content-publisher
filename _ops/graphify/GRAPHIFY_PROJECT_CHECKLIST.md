# Graphify Project Readiness Checklist

Before running Graphify or authorizing implementation, ensure all items are checked.

## Repo Health
- [ ] `git status` is clean.
- [ ] No untracked files in `src/` or `lib/`.
- [ ] `git branch` is aligned with task intent.

## Contextual Documentation
- [ ] `AGENTS.md` is present and updated.
- [ ] `.codex/skills/README.md` exists and is verified.
- [ ] `docs/AGENT_WORKFLOW_MAP.md` reflects current architectural intent.

## Graphify Tools
- [ ] `command -v graphify` results (Binary available: Yes/No).
- [ ] `graphify-out` exists (Last run timestamp: ________).

## Implementation Readiness
- [ ] The task has a clear "Objective".
- [ ] The task has an identified "Risk Level".
- [ ] A backup patch exists if speculative implementation was attempted previously.
