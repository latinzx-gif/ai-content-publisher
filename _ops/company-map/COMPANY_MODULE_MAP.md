# Company Module Map

This document maps the core modules of the HEAD-OFFICE organization to their functions and ownership.

## 01_FASTWORK_DELIVERY
- **Focus**: Delivery of AI content services to clients via Fastwork.
- **Components**:
  - AI Content Publisher
  - Client handoff protocols
  - Service package definitions
  - Support scope
  - Delivery QA
  - Fastwork package documentation

## 02_DATACLAW_ASSET
- **Focus**: Market intelligence and shared data assets.
- **Components**:
  - Market intelligence
  - Brand database
  - Company database
  - Product database
  - Source registry
  - Insight reports

## 03_INVESTMENT_SYSTEM
- **Focus**: Capital allocation and portfolio management.
- **Components**:
  - Capital allocation
  - Risk management
  - Investment strategies
  - Trade logs
  - Performance reviews

## 04_AGENT_OS
- **Focus**: The core "operating system" for agent orchestration.
- **Components**:
  - Agent management
  - Gemini / Codex / Hermes workflow
  - Graphify work checker
  - Agent orchestration documentation

## 05_PRODUCT_CODE
- **Focus**: Source code for the applications.
- **Components**:
  - `head-office-app`
  - AI Content Publisher
  - AgentOps Lite
  - Dashboard
  - Review Queue
  - Content Pipeline

## 06_OPS_AND_AUDIT
- **Focus**: Operational stability and quality assurance.
- **Components**:
  - Graphify
  - QA checklist
  - Smoke tests
  - Deployment readiness
  - Post-audit protocols
