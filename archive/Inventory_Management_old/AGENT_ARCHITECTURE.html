🧠 Agent Roles & Models

🧠

PM Orchestrator

PM Claude Sonnet 4

บทบาท: วางแผน แบ่งงาน ตรวจสอบขอบเขต ประสานงานระหว่าง Agents ทั้งหมด

หน้าที่:
  • อ่าน PRD → เขียน Implementation Plan → แบ่งเป็น Task ย่อย
  • Dispatch งานให้ Agent แต่ละตัวตามความถนัด
  • ตรวจสอบ Output ทุกครั้งก่อน Approve ไปยัง Task ถัดไป
  • Guard Scope — ป้องกัน Feature Creep, ตรวจสอบ Do Not Change
  • อัปเดต Project State Docs (PROJECT_STATE.md, TASK_QUEUE.md)
  • ตัดสินใจเมื่อ Agents มี Conflict

Model แนะนำ: Claude Sonnet 4 — Reasoning ดีเยี่ยม, วางแผนเชิงลึกได้, ภาษาไทยเข้าใจ

🏗️

Master Data Agent

Builder GPT-4o

บทบาท: สร้างระบบข้อมูลหลัก — SKU, Supplier, BOM, สาขา, คลัง, หน่วยนับ

หน้าที่ใน Project:
  • ออกแบบ Database Schema: ตาราง sku, suppliers, branches, warehouses, boms, unit_conversions
  • สร้าง Master Data CRUD UI — จัดการ SKU, Supplier, สาขา, คลัง
  • สร้าง BOM Management — สูตรอาหาร / ส่วนประกอบ
  • ระบบจัดการหน่วยนับ + Conversion Rate
  • เชื่อมต่อ Supabase / PostgreSQL

Model แนะนำ: GPT-4o — สร้าง CRUD ได้เร็ว, Database Schema แม่นยำ

📦

Inventory Ops Agent

Builder Claude Sonnet 4

บทบาท: ระบบปฏิบัติการคลัง — Inbound, Kitchen Requisition, Stock Count, Transfer

หน้าที่ใน Project:
  • Inbound — Goods Receipt, Lot/Expiry, Supplier Reference, Attachment
  • Kitchen Requisition — Request → Approve → Issue → Confirm Receive
  • Stock Count — Plan → Count (Mobile) → Compare → Adjust
  • Transfer — สร้างใบโอน → จองยอด → รับของ → อัปเดตสต๊อก 2 สาขา
  • Stock Movement — ทุก Transaction บันทึก Audit Trail

Model แนะนำ: Claude Sonnet 4 — State Management ซับซ้อน, ตรรกะ Movement ต้องแม่นยำ

✂️

Consumption & Damage Agent

Builder Gemini 2.5 Pro

บทบาท: ตัดสต๊อกตามการใช้จริง + บันทึกของเสียหาย/ชำรุด/หมดอายุ

หน้าที่ใน Project:
  • Consumption Recording — บันทึกการใช้วัตถุดิบจริง รายวัน
  • BOM-based Deduction — คำนวณตัดสต๊อกจากยอดขาย x สูตรอาหาร
  • Damage/Spoilage — บันทึกแยกประเภท พร้อมเหตุผล รูปถ่าย
  • Stock Adjustment — ปรับปรุงยอด พร้อม Approval Workflow
  • แยกรายงาน Consumption ≠ Damage เพื่อให้ผู้บริหารวิเคราะห์ต้นทุน

Model แนะนำ: Gemini 2.5 Pro — การคำนวณปริมาณและตรรกะอนุมัติหลายขั้นตอน

📊

Dashboard & Reports Agent

Builder UI Claude Sonnet 4

บทบาท: สร้าง Dashboard ผู้บริหาร + ระบบรายงาน + Charts + Export

หน้าที่ใน Project:
  • Dashboard KPI Cards — มูลค่าสต๊อก, SKU ต่ำ Min, ใกล้หมดอายุ, สูญเสีย
  • Charts — Trend กราฟสต๊อก, การรับ vs เบิก, การสูญเสียรายเดือน
  • 9 รายงานหลัก — Stock On Hand, Inbound, Consumption, Damage, Transfer, Variance
  • Export — Excel / CSV / PDF
  • Filter — ช่วงเวลา, สาขา, คลัง, หมวดสินค้า

Model แนะนำ: Claude Sonnet 4 — สร้าง Charts/UI สวย, Dashboard Logic ซับซ้อน

📱

Mobile & Barcode Agent

Builder UI GPT-4o

บทบาท: รองรับ Mobile / PDA + Barcode Scanner + Camera Integration

หน้าที่ใน Project:
  • Responsive UI — รับสินค้า, เบิก, ตรวจนับ, ยืนยันรับโอน บนมือถือ
  • Barcode Scanner — สแกน SKU ค้นหาและบันทึกอัตโนมัติ
  • Camera Integration — ถ่ายรูปหลักฐานสินค้าเสียหาย / ชำรุด
  • PDA Support — หน้าจอ Optimized สำหรับเครื่องสแกนคลัง
  • Mobile Dashboard — สรุป Read-only สำหรับผู้บริหาร

Model แนะนำ: GPT-4o — Responsive Design, Camera/Browser API, Frontend Integration

🔍

QA / Validation Agent

QA Gemini 2.5 Pro

บทบาท: ตรวจสอบทุก Implementation ว่าเป็นไปตาม PRD และ Acceptance Criteria

หน้าที่ใน Project:
  • ตรวจสอบ Spec Compliance — Feature ตรงตาม PRD หรือไม่
  • Code Quality Review — Pattern, Security, Performance
  • Acceptance Testing — ทดสอบแต่ละ Feature ตาม Acceptance Criteria
  • Edge Case Detection — หาเคสที่อาจพัง เช่น ติดลบ, ซ้ำซ้อน, Concurrent
  • เขียน Test — Unit Test / Integration Test สำหรับ Business Logic
  • Data Integrity Check — Stock Balance ถูกต้อง, Audit Trail ครบ

Model แนะนำ: Gemini 2.5 Pro — Context Window ใหญ่, ตรวจสอบโค้ดปริมาณมากได้

💡 Multica Agent Bridge Pattern

Agent แต่ละตัวบน Multica จะ:

  • รับ Task Brief จาก PM Orchestrator (Claude Sonnet)
  • ทำงานผ่าน Codex CLI (GPT-5.4) เป็น hands-on executor
  • ส่งผลลัพธ์ไปยัง QA Agent (Gemini 2.5 Pro) เพื่อตรวจสอบ
  • เมื่อ QA Pass → PM Approve → อัปเดต Project State
  • Multica เป็นตัวกลางส่งต่อ Context ระหว่าง Agents
