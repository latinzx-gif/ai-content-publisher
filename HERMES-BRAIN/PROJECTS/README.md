# PROJECTS

This folder is the master registry for all active and archived software development and research projects within HEAD-OFFICE.

## What to store here:
-   A master `PROJECT_REGISTRY.md` file.
-   A sub-folder for each project (e.g., `/DATACLAW_WebApp/`) containing:
    -   High-level project briefs.
    -   Status reports.
    -   Links to the actual source code repository in `/PROJECTS`.

This folder provides a business-level view of the project portfolio, separate from the code itself.
