# KNOWLEDGE

This folder is the long-term repository for reusable, non-project-specific knowledge, patterns, and lessons learned. It's the "shared brain" of the organization.

## What to store here:
-   **Reusable Patterns:** Documents like `DATABASE_PATTERNS.md` or `SECURITY_PATTERNS.md` that can be applied to future projects.
-   **Lessons Learned:** Distilled insights from project post-mortems.
-   **Best Practices:** Guides on topics like "How to Write a Good Prompt" or "Our Approach to Data Validation."
-   **Market Research:** Foundational research that has long-term value outside of a single `DATACLAW` product.
