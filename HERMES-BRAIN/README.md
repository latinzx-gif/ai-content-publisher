# HERMES-BRAIN

This directory is the central, long-term memory and "second brain" for the entire HEAD-OFFICE operation. It is designed to store durable knowledge that transcends individual projects and operating systems.

## Core Folders

-   **/OS**: Contains the specific Operating Systems for each business unit (e.g., `DATACLAW-OS`). An OS defines **how that unit runs**.

-   **/DATA**: A structured repository for the raw and processed data assets generated or used by the operating systems. This is the **valuable output** of the OSes.

-   **/PROJECTS**: Contains the actual source code repositories for software projects (e.g., the web application for DATACLAW, the marketplace for AGENT-TOWN). These are the **tools** that implement the OS workflows.

-   **/HERMES-BRAIN**: The strategic and meta-level knowledge layer that governs everything. This is the **long-term memory and decision-making framework** for the entire organization.
