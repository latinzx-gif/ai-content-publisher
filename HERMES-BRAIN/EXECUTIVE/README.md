# EXECUTIVE

This folder contains documents related to the high-level governance and strategic direction of the entire HEAD-OFFICE portfolio.

## What to store here:
-   `HEAD_OFFICE_DASHBOARD.md`: The main dashboard summarizing the status of all business units.
-   `STRATEGIC_PRIORITIES.md`: The document explaining the "why" behind the P1, P2, P3 priorities.
-   `RESOURCE_ALLOCATION.md`: The framework for allocating time and capital across the portfolio.
-   Quarterly and annual planning documents.
-   High-level financial overviews.
