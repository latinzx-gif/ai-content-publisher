# DECISIONS

This folder acts as an immutable log of all significant strategic, architectural, and product decisions.

## What to store here:
-   **Decision Logs:** Markdown files (`YYYY-MM-DD_decision-name.md`) that record a specific decision.
-   **Meeting Minutes:** Summaries of key meetings (`YYYY-MM-DD_Weekly_Review.md`) where decisions were made.
-   **Architecture Decision Records (ADRs):** Formal documentation for critical technical choices.

The goal is to answer the question "Why did we decide to do X?" months or years later.
