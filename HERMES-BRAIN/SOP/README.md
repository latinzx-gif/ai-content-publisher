# SOP (Standard Operating Procedures)

This folder contains detailed, step-by-step instructions for performing routine and critical business processes. An SOP is a mature, validated workflow.

## What to store here:
-   `SOP-001_NewClientOnboarding.md`: A checklist for bringing on a new client.
-   `SOP-002_ProductLaunch.md`: The process for launching a new intelligence product.
-   `SOP-003_KnowledgeExtraction.md`: The procedure for auditing a project and extracting reusable knowledge (meta!).

The goal is to make processes repeatable, scalable, and easy for new team members to learn.
