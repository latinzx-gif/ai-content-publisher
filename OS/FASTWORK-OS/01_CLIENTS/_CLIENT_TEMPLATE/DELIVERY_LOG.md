# Delivery Log

## Purpose
Track what was delivered to the client, when, by whom, and whether final approval was obtained.

## Required Fields
- Date
- Deliverable
- Version
- Owner agent
- QA status
- Client delivery status
- Approval record
- Follow-up

## AI Agent Usage Rules
- Final client delivery requires manual approval.
- QA Agent audits before or after delivery depending on risk.
- PM Agent records delivery status.
- Document Agent captures reusable components after completion.
