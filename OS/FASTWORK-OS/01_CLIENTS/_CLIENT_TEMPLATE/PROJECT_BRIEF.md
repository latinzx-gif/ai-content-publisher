# Project Brief

## Purpose
Onboard a new Fastwork client with enough context to route work quickly, protect scope, and avoid unnecessary approval gates.

## Required Fields
- Client name
- Contact person
- Client objective
- Business context
- Scope
- Out of scope
- Deliverables
- Timeline
- Budget
- Approval zone
- Success criteria
- Access needed
- Risk notes

## AI Agent Usage Rules
- PM Agent creates the first brief before routing.
- Hermes keeps decisions and context consistent across the project.
- Do not delay low-risk work if the goal and scope are clear.
- Green Zone work can start immediately and be audited later.
- Yellow Zone work requires owner notification, then continues if low risk and reversible.
- Red Zone work requires manual approval before action.
- Manual approval is required only for pricing, contract, payment, production database, deleting data, security credentials, and final client delivery.
- Keep scope and out-of-scope items explicit to prevent unpaid expansion.
