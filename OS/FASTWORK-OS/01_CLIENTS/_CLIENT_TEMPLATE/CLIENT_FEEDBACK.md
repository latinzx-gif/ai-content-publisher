# Client Feedback

## Purpose
Capture client comments, change requests, approvals, and objections in one place.

## Required Fields
- Date
- Source
- Feedback
- Category
- Priority
- Required action
- Owner
- Status

## AI Agent Usage Rules
- PM Agent converts feedback into tasks.
- Hermes preserves client preferences for future work.
- Pricing, contract, payment, and final delivery feedback must be escalated for manual approval.
- QA Agent checks whether feedback was resolved.
