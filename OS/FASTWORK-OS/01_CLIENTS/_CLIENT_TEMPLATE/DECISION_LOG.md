# Decision Log

## Purpose
Record project decisions so agents do not repeat debates or lose client context.

## Required Fields
- Date
- Decision
- Reason
- Decider
- Impact
- Reversal condition

## AI Agent Usage Rules
- Hermes owns memory quality.
- PM Agent records routing and scope decisions.
- Approval-sensitive decisions must name the human approver.
- Low-risk execution decisions can be recorded after work is completed.
