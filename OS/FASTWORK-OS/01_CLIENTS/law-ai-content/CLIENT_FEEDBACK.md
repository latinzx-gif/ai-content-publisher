# Client Feedback

## Purpose
Capture feedback, scope notes, and owner comments related to the AI Content Legal System Fastwork workspace.

## Required Fields
- Date
- Source
- Feedback
- Category
- Priority
- Required action
- Owner
- Status

## AI Agent Usage Rules
- Convert actionable feedback into TASK_QUEUE.md items.
- Pricing, contract, payment, production database, deleting data, security credentials, and final client delivery require manual approval.
- Keep feedback separate from source application code.
