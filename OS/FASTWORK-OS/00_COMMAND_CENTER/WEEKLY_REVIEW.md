# Weekly Review

## Purpose
Executive review for Fastwork-OS to assess revenue, delivery, risk, reusable assets, capacity, and next week's priorities.

## Required Fields
- Week
- Revenue generated
- Projects delivered
- Projects delayed
- Active risks
- Bugs and repeated issues
- New SOPs created
- Reusable assets created
- Upsell opportunities
- Capacity review
- Next week priorities

## AI Agent Usage Rules
- Hermes leads the review and sets next week priorities.
- PM Agent reports delivery status, delays, blockers, and upsell opportunities.
- QA Agent reports bugs, repeated issues, and delivery risks.
- Document Agent reports new SOPs and reusable assets.
- Keep review focused on decisions and next actions.
