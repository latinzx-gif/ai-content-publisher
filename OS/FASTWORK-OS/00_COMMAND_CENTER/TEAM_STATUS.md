# Team Status

## Purpose
Track what each AI agent is doing, what is blocked, and what needs human approval.

## Required Fields
- Agent
- Current assignment
- Status
- Last update
- Blockers
- Output link or location
- Needs human approval

## AI Agent Usage Rules
- Each agent updates its own row after meaningful work.
- Hermes reviews all blocked items and decides whether to route, approve, or defer.
- Do not block low-risk tasks waiting for approval.
- Manual approval flags must be specific and tied to the approved categories.
