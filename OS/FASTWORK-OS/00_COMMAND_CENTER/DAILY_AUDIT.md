# Daily Audit

## Purpose
End-of-day control log for delivered work, open risks, missed cashflow opportunities, and reusable assets created.

## Required Fields
- Date
- Completed deliveries
- Revenue moved forward
- Bugs or risks found
- Client follow-ups
- SOP updates needed
- Tomorrow's top priorities

## AI Agent Usage Rules
- QA Agent drafts the audit after deliveries.
- Hermes reviews patterns and memory updates.
- Document Agent converts repeated fixes into SOP entries.
- Use audit-after-delivery for low-risk tasks instead of delaying execution.
