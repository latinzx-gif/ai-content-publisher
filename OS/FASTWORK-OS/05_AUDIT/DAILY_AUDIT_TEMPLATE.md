# Daily Audit Template

## Purpose
Reusable template for checking daily output, risks, revenue movement, and process improvements.

## Required Fields
- Date
- Work completed
- Revenue impact
- Issues found
- Fixes made
- Open risks
- Green / Yellow / Red review
- SOP updates
- Tomorrow priorities

## AI Agent Usage Rules
- QA Agent completes the audit.
- Hermes extracts priority and memory updates.
- Document Agent updates SOPs from repeated issues.
- Green Zone work is audited after execution.
- Yellow Zone work is checked for owner notification and reversibility.
- Red Zone work is checked for recorded manual approval before action.
- Manual approval is required only for pricing, contract, payment, production database, deleting data, security credentials, and final client delivery.
- Low-risk issues can be fixed immediately and logged after.

## Operating Zones
| Zone | Audit Question | Pass Condition |
|---|---|---|
| Green | Was the work completed and logged? | Output exists and issues are noted |
| Yellow | Was the owner notified and risk low? | Notification recorded and action reversible |
| Red | Was manual approval obtained first? | Approver, date, and approval scope recorded |
