# Bug Log

## Purpose
Track defects, delivery issues, regressions, and recurring problems across client projects.

## Required Fields
- Date
- Client
- Project
- Bug
- Severity
- Owner
- Status
- Fix
- Prevention note

## AI Agent Usage Rules
- QA Agent records bugs and severity.
- Dev Agent records fixes.
- Hermes watches for repeated patterns.
- Document Agent converts recurring fixes into SOP updates.
- Security and production database bugs require manual approval before risky changes.
