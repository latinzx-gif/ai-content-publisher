# Retro

## Purpose
Capture lessons after projects, delays, disputes, and repeated delivery patterns.

## Required Fields
- Date
- Project
- What worked
- What slowed delivery
- Cashflow lesson
- Process change
- Reusable asset
- Owner

## AI Agent Usage Rules
- Hermes leads retros for important projects and repeated issues.
- PM Agent identifies routing or scope lessons.
- QA Agent contributes quality lessons.
- Document Agent turns useful lessons into SOPs and templates.
- Keep retros short and action-focused.
