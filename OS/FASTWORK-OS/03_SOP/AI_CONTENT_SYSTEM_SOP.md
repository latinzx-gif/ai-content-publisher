# AI Content System SOP

## Purpose
Standard process for AI content systems, including prompt flows, content calendars, review steps, and publishing handoff.

- Content goals

- Review workflow
- Publishing scope
- Approval points

## AI Agent Usage Rules
- Research Agent gathers niche and audience context.
- Dev Agent builds automation only within approved access limits.
- QA Agent checks hallucination risk, tone, links, and policy-sensitive claims.
- Manual approval is required for final client delivery, account access, payment, and contract changes.
- Document Agent saves reusable prompts and workflow assets.
