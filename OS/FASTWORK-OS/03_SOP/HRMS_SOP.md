## AI Agent Usage Rules
- Treat employee data and access control as sensitive.
- Manual approval is required for security, production database, payment, and final delivery actions.
- Dev Agent executes only within confirmed scope.
- QA Agent checks permissions, sample records, forms, exports, and edge cases.
- Document Agent prepares admin and user guidance.
