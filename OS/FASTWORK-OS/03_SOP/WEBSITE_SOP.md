# Website SOP

## Purpose
Standard process for Fastwork website projects from intake to handoff.

## Required Fields
- Client goal
- Pages required
- Content status
- Design references
- Build tasks
- QA checklist
- Delivery approval

## AI Agent Usage Rules
- PM Agent confirms scope and pages.
- Dev Agent builds within agreed package limits.
- QA Agent audits responsiveness, links, forms, copy, and client requirements.
- Final client delivery requires manual approval.
- Low-risk content and layout fixes can be executed before audit.
