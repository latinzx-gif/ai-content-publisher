# Client Requirement Bank

## Purpose
Store common client requirements, questions, objections, and accepted solutions for faster future delivery.

## Required Fields
- Requirement
- Client type
- Service type
- Standard response
- Delivery approach
- Risk level
- Reusable asset

## AI Agent Usage Rules
- Research Agent and PM Agent add repeated requirements.
- Dev Agent uses accepted delivery approaches when scope matches.
- QA Agent checks whether standard requirements were missed.
- Document Agent links reusable assets.
- Remove sensitive client details before reuse.
