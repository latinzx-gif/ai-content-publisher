# UX Patterns

## Purpose
Store reusable UX patterns for client websites, dashboards, forms, admin tools, and handoff flows.

## Required Fields
- Pattern name
- Use case
- Client type
- Why it works
- Implementation notes
- QA checks

## AI Agent Usage Rules
- Dev Agent uses proven patterns before inventing new layouts.
- QA Agent checks usability against the selected pattern.
- Document Agent adds patterns after successful delivery.
- Avoid adding client-sensitive information.
