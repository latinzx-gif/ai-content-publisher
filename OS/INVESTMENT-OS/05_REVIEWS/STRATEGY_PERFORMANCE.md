# Strategy Performance

## Purpose
Track expected vs actual performance by strategy.

## Required Fields
- Strategy
- Capital deployed
- Expected return
- Actual return
- Max drawdown
- Risk score
- Decision

## Operating Rules
- Strategies earn more capital only after proven risk-adjusted performance.
- Losing or unclear strategies get reduced or paused.
- Do not evaluate yield without liquidity and counterparty risk.

## Template
| Strategy | Capital Deployed | Expected Return | Actual Return | Max Drawdown | Risk Score | Decision |

|  |  |  |  |  |  | Add / Hold / Reduce / Stop |
