# Monthly Review

## Purpose
Review capital deployment, returns, risk, cashflow, mistakes, and next-month allocation.

## Required Fields
- Month
- Net worth / capital base
- Actual return
- Expected return
- Cashflow generated
- Drawdown
- Best / worst strategy
- Allocation changes
- Next actions

## Operating Rules
- Review actual returns against expected returns.
- Reduce or pause strategies that violate risk rules.
- Increase only strategies with proven risk-adjusted performance.
