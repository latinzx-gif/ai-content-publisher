# Arbitrage

## Purpose
Track arbitrage opportunities across platforms, assets, funding, or markets.

## Required Fields
- Opportunity
- Platforms
- Spread
- Fees
- Capital required
- Execution risk
- Liquidity
- Exit rule

## Operating Rules
- Net return must include fees, slippage, funding, transfer time, and taxes where relevant.
- Counterparty and withdrawal risk must be scored.
- Do not deploy if exit path is unclear.
