# Grid Trading

## Purpose
Manage spot grid strategies for range-bound markets and cashflow generation.

## Required Fields
- Asset pair
- Platform
- Capital deployed
- Grid range
- Expected return
- Max loss
- Exit rule
- Review date

## Operating Rules
- Use only assigned trading or experiment capital.
- Define range, stop condition, and review date before launch.
- Do not assume grid yield is risk-free.
