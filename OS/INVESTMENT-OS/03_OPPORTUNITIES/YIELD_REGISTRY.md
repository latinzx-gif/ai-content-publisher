# Yield Registry

## Purpose
Track where capital can earn yield and compare return, liquidity, lock-up, and counterparty risk.

## Required Fields
- Yield opportunity
- Platform / protocol
- Asset
- APY
- Liquidity
- Lock-up
- Counterparty risk
- Status

## Operating Rules
- Highest APY is not automatically best.
- Yield must be adjusted for risk, liquidity, and platform reliability.
- Stablecoin, DeFi, staking, lending, and grid yield must be separated.

## Template
| Yield Opportunity | Platform / Protocol | Asset | APY | Liquidity | Lock-Up | Counterparty Risk | Status |
|---|---|---|---:|---|---|---|---|
|  |  |  |  | Immediate / Daily / Weekly / Locked |  | Low / Medium / High | Watch / Active / Paused / Rejected |
