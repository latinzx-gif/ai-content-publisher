# Portfolio Manager

## Purpose
Manage core investment allocation, DCA plans, rebalancing, and portfolio reviews.

## Required Fields
- Asset class
- Target allocation
- Current allocation
- Drift
- DCA plan
- Rebalance action

## Operating Rules
- Keep long-term portfolio separate from active trading.
- Rebalance by policy.
- Protect emergency cash before adding risk.
