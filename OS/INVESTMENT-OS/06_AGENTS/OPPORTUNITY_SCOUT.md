# Opportunity Scout

## Purpose
Find and compare global capital deployment opportunities across investments, yield, trading, and cash management.

## Required Fields
- Opportunity
- Strategy type
- Expected return
- Platform / protocol
- Risk level
- Liquidity
- Recommendation

## Operating Rules
- Scout opportunities, but do not deploy capital.
- Compare risk-adjusted return, liquidity, lock-up, and counterparty risk.
- Register promising opportunities before allocation.

## Template
| Opportunity | Strategy Type | Expected Return | Platform / Protocol | Risk Level | Liquidity | Recommendation |
|---|---|---:|---|---|---|---|
|  | Core / Yield / Trading / Experiment |  |  | Low / Medium / High |  | Watch / Review / Reject |
