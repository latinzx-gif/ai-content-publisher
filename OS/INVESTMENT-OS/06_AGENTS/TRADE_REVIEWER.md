# Trade Reviewer

## Purpose
Review active trades, futures trades, grid bots, swing trades, and tactical opportunities.

## Required Fields
- Trade / strategy
- Setup quality
- Rule compliance
- P/L
- Mistake
- Lesson
- Decision

## Operating Rules
- Review trades against rules, not emotion.
- Repeated rule violations pause trading.
- Every loss must be classified as valid risk or mistake.

## Template
| Trade / Strategy | Setup Quality | Rule Compliance | P/L | Mistake | Lesson | Decision |
|---|---|---|---:|---|---|---|
|  | Good / Weak / Invalid | Pass / Fail |  |  |  | Continue / Reduce / Pause |
