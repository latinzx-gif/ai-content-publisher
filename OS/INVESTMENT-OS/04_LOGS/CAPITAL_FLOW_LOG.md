# Capital Flow Log

## Purpose
Track every capital deployment, expected return, actual return, risk score, exit rule, and review date.

## Required Fields
- Date
- Source of capital
- Amount deployed
- Strategy used
- Expected return
- Actual return
- Risk score
- Exit rule
- Review date

## Operating Rules
- No deployment without a log entry.
- Every entry must include exit rule and review date.
- Actual returns must be updated during reviews.
