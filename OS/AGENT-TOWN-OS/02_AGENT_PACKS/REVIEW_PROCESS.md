# Review Process

## Purpose
Define how agent packs are reviewed before marketplace listing.

## Required Fields
- Pack
- Reviewer
- Review status
- Quality result
- Issues
- Decision
- Follow-up

## AI Usage Rules
- Review for usefulness, clarity, repeatability, safety, and monetization fit.
- Do not approve packs that cannot produce a reliable buyer outcome.
- Record review decisions in PACK_CATALOG.md.
