# Pack Catalog

## Purpose
Registry of agent packs treated as marketplace products.

## Required Fields
- Pack name
- Category
- Creator
- Status
- Target user
- Price tier
- Reuse count
- Notes

## AI Usage Rules
- Track each pack as a product with owner, version, and quality status.
- Prioritize packs with repeatable demand.
- Do not list packs without basic submission and quality checks.
