# Workflow Library

## Purpose
Store reusable workflows for marketplace operations, creator onboarding, review, and product execution.

## Required Fields
- Workflow name
- Use case
- Steps
- Owner
- Status
- Reuse count
- Notes

## AI Usage Rules
- Workflows must be executable and repeatable.
- Keep steps short and decision-oriented.
- Convert repeated workflows into product features when useful.
