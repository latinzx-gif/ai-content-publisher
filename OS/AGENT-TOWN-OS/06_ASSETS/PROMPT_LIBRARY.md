# Prompt Library

## Purpose
Store reusable prompts for building, reviewing, marketing, and operating agent packs.

## Required Fields
- Prompt name
- Use case
- Inputs
- Output
- Owner
- Status
- Notes

## AI Usage Rules
- Prompts should be reusable across packs or operations.
- Include inputs and expected output.
- Remove prompts that produce inconsistent or vague results.
