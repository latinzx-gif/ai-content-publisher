# Asset Registry

## Purpose
Track reusable assets that support Agent Town before scaling the marketplace.

## Required Fields
- Asset name
- Type
- Category
- Status
- Owner
- Reuse count
- Notes

## AI Usage Rules
- Build assets before scaling.
- Assets must support product, marketplace, creators, or revenue.
- Deprecate assets that are stale or unused.
