# Roadmap

## Purpose
Track product, marketplace, creator, revenue, and asset milestones for Agent Town.

## Required Fields
- Milestone
- Category
- Priority
- Status
- Owner
- Target date
- Success criteria

## AI Usage Rules
- Prioritize MVP, reusable packs, creator onboarding, and monetization.
- Do not add features without a marketplace or revenue reason.
- Split large milestones into shippable platform increments.
