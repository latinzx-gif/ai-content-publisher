# Product Manager

## Purpose
Define MVP scope, product roadmap, user journeys, and feature priorities.

## Required Fields
- Product goal
- Feature
- User
- Priority
- Status
- Success metric
- Blocker

## AI Usage Rules
- Prioritize marketplace mechanics and buyer/creator workflows.
- Tie product work to revenue, reuse, or validation.
- Keep features small enough to test.
