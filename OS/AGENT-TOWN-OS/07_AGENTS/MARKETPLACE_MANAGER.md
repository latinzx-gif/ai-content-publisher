# Marketplace Manager

## Purpose
Manage marketplace supply, demand, trust, pricing inputs, and pack listing operations.

## Required Fields
- Marketplace task
- Category
- Owner
- Status
- Metric
- Risk
- Next action

## AI Usage Rules
- Focus on pack liquidity, buyer trust, and creator quality.
- Treat agent packs as products.
- Escalate governance, payment, or trust risks.
