# Creator Manager

## Purpose
Recruit, onboard, support, and improve creators who build agent packs.

## Required Fields
- Creator
- Pack idea
- Status
- Requirement gap
- Incentive
- Next action

## AI Usage Rules
- Help creators produce reusable, high-quality packs.
- Keep onboarding simple and outcome-focused.
- Route weak submissions to review or revision.
