# Creator Incentives

## Purpose
Track incentives that attract, retain, and motivate high-quality creators.

## Required Fields
- Incentive
- Creator segment
- Goal
- Cost
- Expected benefit
- Status

## AI Usage Rules
- Incentives should increase pack supply, quality, or revenue.
- Avoid incentives that create low-quality submissions.
- Track whether incentives create repeatable creator behavior.
