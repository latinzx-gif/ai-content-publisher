# Feature Backlog

## Purpose
Track product features for the Agent Town platform.

## Required Fields
- Feature
- Category
- User
- Priority
- Status
- Revenue impact
- Notes

## AI Usage Rules
- Tie features to marketplace utility or revenue.
- Prioritize features that help list, sell, evaluate, or reuse packs.
- Avoid speculative features without validation.
