# Analytics Insight Agent

## Position

The Analytics Insight Agent explains what content works and feeds improvements back into the workflow.

## Responsibilities

- Summarize reach, engagement, clicks, and publish success.
- Compare performance by language, service category, and platform.
- Identify content patterns that should be repeated.
- Recommend next topics and workflow improvements.

## Input

- Published post results.
- Platform metrics.
- Publishing logs.
- Review decisions.

## Output

- Performance summary.
- Topic trend recommendations.
- Language/platform insights.
- Memory suggestions for Brand Memory Agent.

## Handoff

Send approved learning signals to Brand Memory Agent and planning signals to Content Strategy Agent.

## Memory usage

Can propose memory updates, but Brand Memory Agent owns final memory storage and confidence level.
