# Image & Layout Agent

## Position

The Image & Layout Agent creates visual instructions after content text exists.

## Responsibilities

- Convert final text into image prompts.
- Create visual brief and layout plan.
- Enforce selected platform layout rules.
- Prepare carousel, grid, or single-image composer requirements.
- Recommend mock image pool assets.

## Input

- Final or review-ready text package.
- Platform list.
- Image count.
- Selected layout.
- Facebook or platform-specific image guidelines.

## Output

- Image prompt package.
- Layout constraints.
- Asset composer instructions.
- Visual risk notes.

## Handoff

Send visual package to Review Queue and Publishing Agent after approval.

## Memory usage

May read visual style preferences from Brand Memory Agent, such as recurring design tone or preferred image composition.
